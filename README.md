# مبادرة تمثيل الطلاب في المنتدى العالمي للبيانات

نسخة تجريبية عربية متجاوبة لمنصة اختيار ممثلي طلاب الجامعات في منتدى الأمم المتحدة العالمي السادس للبيانات 2026. تشمل رحلة الطالب ولوحة تحكم تجريبية، وتعمل دون قاعدة بيانات أو تثبيت حزم.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث.

ولتشغيله عبر خادم محلي (اختياري):

```powershell
python -m http.server 8000 --directory outputs
```

ثم افتح: `http://localhost:8000`

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
3. افتح `Settings` ثم `Pages`.
4. اختر `Deploy from a branch`.
5. اختر فرع `main` والمجلد `/ (root)` ثم اضغط `Save`.

سيظهر رابط الموقع بعد اكتمال النشر خلال دقائق قليلة.

## تجربة التدفق

- استخدم بريدًا تجريبيًا ينتهي بـ `edu.sa`.
- في شاشة التحقق، أدخل أي ستة أرقام.
- ينتقل الطالب بعد التحقق مباشرة إلى الأسئلة العشرة المعتمدة.
- تُحفظ إجابات الأسئلة محليًا في المتصفح.
- افتح «لوحة الإدارة» من الهيدر لتجربة المؤشرات والجداول والسحب الإلكتروني.
- الرقم السري التجريبي للوحة الإدارة: `1406`.
- الأسئلة العشرة معتمدة، ويمكن مراجعة محاورها وإجاباتها من تبويب «الأسئلة» في لوحة الإدارة.

> جميع الأسماء والأرقام والنتائج بيانات تجريبية لأغراض العرض فقط.

## ملاحظات مهمة

- الشعار مضمّن داخل المشروع ولا يعتمد على ملف مؤقت في الجهاز.
- خط الهوية وشعار الهيئة يُحمّلان عبر الإنترنت.
- حماية لوحة الإدارة الحالية تجريبية فقط، وليست بديلًا عن تسجيل دخول آمن من الخادم.
- التسجيل والنتائج تجريبية ولا تُرسل إلى قاعدة بيانات.
